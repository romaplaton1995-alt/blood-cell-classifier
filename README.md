# 🩸 Классификатор клеток крови (ResNet50)

> Автор: Платон Роман, Б24-302, 2026, МИФИ

## Краткое описание

Проект реализует систему автоматической классификации клеток крови на микроскопических изображениях. 
Модель на основе ResNet50 обучена распознавать 11 типов клеток с акцентом на раннее выявление патологических форм (бласты, миелоциты, метамиелоциты).

**Ключевые метрики:**
- Точность (Accuracy): 94.83%
- F1-score (weighted): 94.80%
- Recall для бластов: 95.35%

## Быстрый запуск

### Требования
- Docker ≥ 24.0
- Docker Compose ≥ 2.0
- NVIDIA GPU + nvidia-container-toolkit (опционально, для ускорения)

### Установка и запуск
```bash
# Клонировать репозиторий
git clone https://github.com/romaplaton1995-alt/blood-cell-classifier.git
cd blood-cell-classifier

# Запустить (модель скачается автоматически)
docker compose --profile web up --build
```
#### - После запуска откройте в браузере: http://localhost:7860

## Клиническая значимость
Модель оптимизирована под выявление наиболее опасных клеток по принципу увеличения значения Recall. 
Для опухолевых классов (Бласты, Миелоциты, Метамиелоциты) увеличены веса функции потерь, 
что обеспечивает высокую чувствительность (Recall > 90%).
```bash
| Класс            | Тип              | Клиническая интерпретация                        |
|------------------|------------------|--------------------------------------------------|
| Бласты           | Патология        | ≥20% = диагноз острого лейкоза (ВОЗ)             |
| Миелоциты        | Услов. патология | Появление в крови = миелопролиферативный процесс |
| Метамиелоциты    | Услов. патология | ""Сдвиг влево"", инфекция, лейкоз                |
| Остальные        | Норма/реакция    | Оценка количества в лейкоцитарной формуле        |
```
### Важно: Система является вспомогательным инструментом. Окончательный диагноз ставит врач-гематолог.
